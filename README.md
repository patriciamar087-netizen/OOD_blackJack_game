What is the difference between data stored in a Card object and behavior provided by its methods?
    -Data in a Card object is the information it stores, like rank and suit.
Behavior is what the card can do, such as flipping or comparing itself to another card.

What did you learn from modifying an existing Java program instead of writing everything from scratch?
    -Modifying an existing program teaches you how real code is structured and how different classes work together.
It also helps you learn to extend and improve code without breaking what already works.
